# Livros de programação

Nove e-books gratuitos da GoalKicker, consultados em 22/09/2026. Autoria coletiva dos colaboradores do Stack Overflow Documentation, organização GoalKicker. Resumos próprios em português; conteúdo original dos livros em inglês. Preço zero refere-se à edição digital gratuita. Capas pertencem aos respectivos titulares. URLs de origem e das capas no JSON.

Para importar no banco configurado: `php database/seeds/importar-livros.php`. Executar somente no terminal. Não duplica títulos nem modifica registros existentes. As capas de assets/capas são copiadas para uploads/livros.
